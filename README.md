## 5주차 JavaScript 인터랙션 추가

### 확인할 문제
이메일 구독 폼을 제출해도 화면에 아무 반응이 없어서 신청 여부를 알 수 없었다.

### 수정한 내용
- 구독 폼의 submit 이벤트를 JavaScript로 처리했다.
- 이메일을 입력하지 않으면 안내 메시지를 보여주고 입력창에 포커스를 주었다.
- 신청이 완료되면 입력한 이메일과 함께 완료 메시지를 표시했다.
- 완료 메시지에 is-success 클래스를 추가해 성공 스타일을 적용했다.
- 신청 후 버튼 문구를 "신청 완료"로 바꾸고 disabled 상태로 만들었다.
- 구독 상태(isSubcribed)와 신청 횟수(submitCount)를 변수로 관리했다.

### 확인할 동작
이메일 빈 값 제출 / 이메일 입력 후 제출 / 제출 후 버튼 비활성화
